Aurora DS5 is a fork of Aurora — itself a fork of Moonlight TV — for LG webOS, tuned for high-bitrate 4K/120Hz HDR streaming from a Sunshine or NVIDIA GameStream host, with an AMOLED-friendly dark theme and a UI built for TV remotes and gamepads. It adds a DualSense transport that ships inside the package.

DualSense (DS5) transport

webOS meters Bluetooth HID output to roughly 62 reports per second with 30–67 ms of air jitter, which is not enough to carry controller audio. Aurora DS5 bundles a small root helper that writes raw HCI ACL frames instead, so a DualSense gets headset audio, microphone LED, player LED and haptics while streaming.

  • The helper travels inside the package and is elevated through the Homebrew Channel's own elevate-service — nothing has to be copied onto the TV by hand.
  • Its service API is restricted to this app before elevation, so no other app on the TV can reach a root service.
  • Root is optional. On a TV without it, the app falls back to the plain hidraw controller path and behaves like upstream Aurora.

Highlights

  • AMOLED layout — pure black background, dark surfaces, violet accent across the launcher, game grid, and settings.
  • 3.6K resolution (3584×2016) — ~90% of 4K pixel area with less decoder load and lower input lag than native 4K on recent LG panels.
  • HDR10 (PQ) over HEVC Main10 when the host supports it.
  • NTSC-correct refresh rates (59.94/119.88 Hz for 60/120 FPS) for smoother sync on LG panels.
  • Periodic decoder refresh for HEVC, avoiding long-session artifact drift.

Controllers

Gamepads use standard Moonlight/SDL input. PlayStation DualSense controllers get adaptive triggers, player LED, mic LED, and rumble feedback from the host when Sunshine supports it.

  • Configurable analog stick deadzone and ABXY swap for Nintendo-style layouts.
  • Virtual mouse mode: LB + RS during streaming (enable in Settings → Input).
  • Full soft keyboard: RB + RS or remote blue button during streaming.

Built for TV remotes and gamepads

  • On-screen streaming overlay with live latency/bitrate stats, opened with the remote's red button or a gamepad combo.
  • Full soft keyboard (Windows/Xbox OSK style) with sticky modifiers, openable directly from the gamepad.
  • Virtual mouse mode for desktop apps and launchers — right stick moves the cursor, left stick scrolls.
  • Auto-resume of a running app when Aurora returns to the foreground.
